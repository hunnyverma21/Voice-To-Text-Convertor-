# Voice to Text Converter

A responsive voice-to-text web app built with HTML, CSS, and JavaScript using the browser's Web Speech API.

## Features
- Speech recognition with language selection (English India, Hindi, English US/UK, Spanish, French, German, Japanese)
- Live transcription into an editable text box
- Start and stop listening controls
- Word count
- Copy text to clipboard
- Download transcript as a `.txt` file
- Responsive dark UI

## Run
1. Extract the ZIP.
2. Open `index.html` in an up-to-date Chrome or Edge browser.
3. Allow microphone access and click **Start speaking**.

## Notes
- Browser support varies; Chrome or Edge is recommended.
- Speech recognition may use the browser/vendor's online recognition service and may require an internet connection.
- Microphone access may require a secure context such as HTTPS or localhost when hosted.
- This is a front-end demo; it does not store transcripts on a server.
